# PIT II — Cupcakes Gourmet | Markus Vinicius Melo Porto

Projeto acadêmico de **Markus Vinicius Melo Porto — RGM 33238588**, desenvolvido como continuidade da PIT I.

## Contexto
Na PIT I foi escolhida a **Situação-Problema 2**, relacionada à construção dos principais artefatos UML para o aplicativo de uma loja virtual de cupcakes.

O projeto considerou os atores e funcionalidades envolvidos nos fluxos de:
- cliente;
- administrador;
- entregador;
- gateway de pagamento;
- compra;
- pagamento;
- entrega;
- gerenciamento de produtos e pedidos.

## Objetivo
Dar continuidade à modelagem desenvolvida na PIT I, transformando os requisitos e artefatos UML em uma solução funcional, documentada e testável.

## Base da PIT I
- UML;
- casos de uso;
- casos de uso expandidos;
- diagrama de classes;
- diagrama de sequência;
- levantamento de requisitos;
- regras de negócio;
- orientação a objetos.

## PIT II
Nesta etapa, a proposta é implementar uma aplicação web responsiva que represente o fluxo principal do sistema de cupcakes, mantendo a documentação e o código-fonte no GitHub.
